A deterministic Node program that raids a midnight fridge, roasts every item it finds, and writes the roast to `entry.txt`. No network, no clock, no randomness — every run produces byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
